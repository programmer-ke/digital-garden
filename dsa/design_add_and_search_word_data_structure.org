* Design Add and Search Word Data Structure

** Description

https://neetcode.io/problems/design-word-search-data-structure/question

** Approach

- Use a prefix tree data structure to store words
- when searching words:
  - without any dots, follow exact path down the tree
  - If we have dots, subtitute it for all branches along the path
    and find the first possible match

** Solution

#+begin_src python
class Node:
    def __init__(self):
        self.children = {}
        self.end_of_word = False
        
class WordDictionary:

    def __init__(self):
        self.root = Node()

    def addWord(self, word: str) -> None:
        curr = self.root
        for c in word:
            if not c in curr.children:
                curr.children[c] = Node()
            curr = curr.children[c]
        curr.end_of_word = True

    def search(self, word: str) -> bool:
        return self.dfs(word, self.root, from_index=0)

    def dfs(self, word, node, from_index):
        if from_index == len(word):
            return node.end_of_word

        c = word[from_index]
        if c == ".":
            for child in node.children.values():
                if self.dfs(word, child, from_index + 1):
                    return True
            return False

        if not c in node.children:
            return False

        return self.dfs(word, node.children[c], from_index + 1)
            
#+end_src

** Analysis

*** Time Complexity

O(n) for adding a word of length n

O(n) for searching a word of length n. Dots add at most 26^{2}n time

*** Space complexity

O(m*n) worst case for m words of length n
