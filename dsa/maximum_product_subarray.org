* Maximum Product Subarray

** Description

https://leetcode.com/problems/maximum-product-subarray/description/


** Approach

*** Modified Kadane's Algorithm

- Traverse the array from left to right, at each position track:
  - the largest product ending at that position
  - the smallest product ending at that position
  - the largest product seen so far

- We track the smallest product seen upto a given position because it
  could be a large negative that could turn into a large positive if
  current item is negative
  

** Solution

#+begin_src python
from typing import List


class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        max_p = nums[0]
        curr_max, curr_min = 1, 1
        for n in nums:
            old_max = curr_max
            curr_max = max(n, old_max * n, curr_min * n)
            curr_min = min(n, curr_min * n, old_max * n)
            max_p = max(max_p, curr_max)
        return max_p

nums = [2,4,-3,5]

# Output: 8
assert Solution().maxProduct(nums) == 8


nums = [-3,0,-2]

#Output: 0
assert Solution().maxProduct(nums) == 0
