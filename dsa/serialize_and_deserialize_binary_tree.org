* Serialize and Deserialize Binary Tree

** Description

https://leetcode.com/problems/serialize-and-deserialize-binary-tree/description/

** Approach

a) Need a way to traverse all nodes in the tree
 - To easily reconstruct the tree, we need to access parent nodes
   before their child nodes. Pre-order dfs and bfs are options here.
b) Need some way to preserve the structure of the tree
 - Including the null children of the terminal nodes preserves
   strucure
c) Need to encode tree into a string for transmission
 - We can use the commma separated node values, with N for null
   placeholders

** Solution

#+begin_src python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Codec:
    
    # Encodes a tree to a single string.
    def serialize(self, root: Optional[TreeNode]) -> str:
        tree = []
        def dfs(node):
            if node is None:
                tree.append("n")
            else:
                tree.append(str(node.val))
                dfs(node.left)
                dfs(node.right)
        dfs(root)
        return ",".join(tree)
        
    # Decodes your encoded data to tree.
    def deserialize(self, data: str) -> Optional[TreeNode]:
        def dfs():
            nonlocal i
            if tree[i] == "n":
                i += 1
                return None
            val = int(tree[i])
            node = TreeNode(val)
            i += 1
            node.left = dfs()
            node.right = dfs()
            return node
        
        tree = data.split(",")
        i = 0
        return dfs()
    
#+end_src

** Analysis

*** Time complexity

O(n) - we traverse through each node once both serializing and deserializing

*** Space complexity

O(h), h == n worst case (skewed tree) for the recursion stack
