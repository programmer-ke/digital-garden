** Approach 1

- use an adjacency list to map courses to their depencencies
- use dfs to determine whether a course can be completed without
  circular depencencies

** Solution 1

#+begin_src python
from typing import List

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        self.deps = {}
        for course, dep in prerequisites:
            if course not in self.deps:
                self.deps[course] = [dep]
            else:
                self.deps[course].append(dep)
        self.visited = set()
        for course in range(numCourses):
            if not self.satisified(course):
                return False
        return True

    def satisified(self, course):
        if course not in self.deps:
            # has no deps, satisified
            return True
        if course in self.visited:
            # cycle detected in search path
            return False

        self.visited.add(course)

        for dep in self.deps[course]:
            if not self.satisified(dep):
                return False

        self.visited.remove(course)
        del self.deps[course]  # all dependencies satisified
        return True

numCourses, prerequisites = 2, [[0,1]]

assert Solution().canFinish(numCourses, prerequisites)

** Approach 2

- use topological sort:
  - create a frequency map of dependants for each course
  - create an adjacency list mapping each course to its dependencies
  - use a queue to process courses without dependants until there's none left
  - if all courses processed, then there are no cycles  

** Solution 2

#+begin_src python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:

        num_dependants = [0] * numCourses
        deps = [[] for _ in range(numCourses)]

        for course, dep in prerequisites:
            num_dependants[dep] += 1
            deps[course].append(dep)

        # add courses with no dependants to queue
        q = deque([])
        for c in range(numCourses):
            if num_dependants[c] == 0:
                q.append(c)

        # process courses via bfs
        finished = 0
        while q:
            c = q.popleft()
            finished += 1

            # update dependencies
            for dep in deps[c]:
                num_dependants[dep] -= 1
                if num_dependants[dep] == 0:
                    q.append(dep)

        return finished == numCourses

numCourses, prerequisites = 2, [[0,1]]

assert Solution().canFinish(numCourses, prerequisites)
#+end_src

_AI_:

Topological sort shows up whenever there's a dependency ordering
problem:

- *Build systems* — Make/Bazel compiling targets in dependency order;
  detecting circular includes/imports
- *Package managers* — npm/pip/apt resolving install order; failing on
  circular dependencies
- *Course prerequisites* — literally this problem, also degree
  planning tools
- *Task scheduling* — CI/CD pipelines, cron jobs, workflow engines
  (Airflow) where tasks have ordering constraints
- *Spreadsheets* — detecting circular cell references (=A1=B1+1,
  B1=A1+1=)
- *Linkers* — resolving symbol dependencies between modules
- *Database queries* — join ordering, view dependency resolution
