* Reverse a Linked List

** Description

https://leetcode.com/problems/reverse-linked-list/description/

** Approach

We'll iterate through the list reversing the pointers. To prevent
losing track of references, we'll use 3 pointers: current, previous
and temp.

** Solution

#+begin_src python
from typing import Optional
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next



class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev = None
        curr = head

        while curr:
            temp = curr.next
            curr.next = prev
            prev = curr
            curr = temp

        return prev
    

vals = [0,1,2,3]
head = None
for v in reversed(vals):
    n = ListNode(v, head)
    head = n
    
new_head = Solution().reverseList(head)

curr = new_head

while curr:
    print(curr.val)
    curr = curr.next
#+end_src

Another hint: After the recursive call, you need to link the /last/

from typing import Optional
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next



class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None

        new_head = head
        if head.next:
            new_head = self.reverseList(head.next)
            # head.next is now the tail of the new list
            # link it back to old head
            head.next.next = head
            head.next = None
        return new_head

vals = [0,1,2,3]
head = None
for v in reversed(vals):
    n = ListNode(v, head)
    head = n
    
new_head = Solution().reverseList(head)

curr = new_head

while curr:
    print(curr.val)
    curr = curr.next

appears as a building block in several real-world systems:

  sequences).
- *Arithmetic on big numbers* – Numbers stored as linked lists (digit
  by digit) are reversed to align least-significant digits for
  addition/multiplication.

  prepending; reversing is a core operation for transformations.
