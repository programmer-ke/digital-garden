* Longest Substring Without Repeating Characters

** Description

https://leetcode.com/problems/longest-substring-without-repeating-characters

** Approach

The brute force approach is to use two pointers into the string.
For each position of the first pointer, iterate the second pointer
to identify a non-repeating substring.

We can use a set to track 'seen' characters.

Return the longest such substring found. This would be an O(n^{2})
time complexity approach.

There could be an O(n) approach:

We start with the both pointers pointing to the first character.
As long as there are characters left that haven't been seen,
we advance the right pointer. If that's not the case,
we calculate the length of the current substring and if it is the
longest one seen so far, store its indices.

If there are characters left that havent been seen, advance the
left pointer by one, remove the character it was pointing to from
the tracking set and repeat.

We do this until the right pointer gets to the end of the string.

The we return longest substring seen so far using its indices

** Solution

#+begin_src python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return n
        left, right = 0, 0
        max_len = 0
        seen = {s[right]}
        while right < n - 1:
            nxt = s[right + 1]
            if nxt in seen:
                curlen = right - left + 1
                max_len = max(curlen, max_len)
                seen.remove(s[left])
                left += 1
            if not nxt in seen:
                seen.add(nxt)
                right += 1
        max_len = max(max_len, right - left + 1)
        return max_len

#+begin_src python

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        table = [-1] * 128
        left = 0
        maxlen = 0
        for right, c in enumerate(s):
            ord_c = ord(c)
            if table[ord_c] >= left:
                # advance left to maximize window size without c
                left = table[ord_c] + 1
            table[ord_c] = right
            maxlen = max(right - left + 1, maxlen)
        return maxlen
