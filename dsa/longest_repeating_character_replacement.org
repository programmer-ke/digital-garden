* Longest Repeating Character Replacement

** Description

https://neetcode.io/problems/longest-repeating-substring-with-replacement

** Approach

The brute force approach would be to use two pointers into the string.
For every character pointed to with the left pointer, we try and find
the longest substring of similar characters in the rest of the string
that allows to most k replacements.

This would have a time complexity of O(n^{2}) worst case.

We can have a more optimized version using a sliding window.

We have a left and a right pointer delimiting a substring which can
allow upto k replacements for the same character.

As we advance the right pointer, if we discover we need to replace
more than k characters to get a repeating substring, we advance the
left pointer until we satisfy the condition.

The invariant we need to retain is:

length_of_subtring - max_frequency_repeating_character <= k

We'll return the maximum substring length that satisfies this
condition.

We determine length of the substring by calculating:

right - left + 1

We track the repeating character frequency in the window using a
mapping of each character in the window with their frequency.

Every time we advance the right left pointer, we decrement the
character frequency in the window.

** Solution

#+begin_src python

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        max_freq = max_len = left = 0
        count = {}

        for right, char in enumerate(s):
     
            count[char] = count.get(char, 0) + 1
            max_freq = max(count[char], max_freq)

            substr_len = right - left + 1
            while substr_len - max_freq > k:

                count[s[left]] -= 1

                left += 1

                max_freq = max(count.values())
                substr_len = right - left + 1

            max_len = max(max_len, (right - left + 1))

        return max_len

s = "XYYX"
k = 2
print(Solution().characterReplacement(s, k)) # -> 4

s = "AAABABB"
k = 1
print(Solution().characterReplacement(s, k)) # -> 5

#+end_src

** Analysis

*** Time complexiy

Since we're iterating the right pointer through the string once,
and for each iteration we do atmost 26^{2} operations,

the time complexity is O(n*26), which comes to O(n) without constants.

*** Space complexity

We use a mapping to track counts, which will hold atmost 26 character.

Space complexity is therefore O(26), which is O(1) constant space usage.
