* Combination Sum

** Description

https://leetcode.com/problems/combination-sum/description/

** Approach 1

- Use dfs backtracking to enumerate all possible terms that add up to the target
  - execute two branches recursively:
    - As many repeating possibilities with the given starting candidate in the list
    - As many possibilities with the next candidate
    - base cases:
      - sum equals target
      - sum exceeds target or candidate list exhausted
  - This creates a dfs tree of all possible candidates for the solution

** Solution 1

#+begin_src python
from typing import List

class Solution:
    def combinationSum(self, nums: List[int], target: int) -> List[List[int]]:
        self.results = []
        self.target = target
        self.candidates = nums
        
        self.dfs(0, [], 0)
        return self.results

    def dfs(self, start, collection, total):
        if total == self.target:
            self.results.append(collection.copy())
            return

        if total > self.target or start >= len(self.candidates):
            return

        # repeating branch
        collection.append(self.candidates[start])
        self.dfs(start, collection, total + self.candidates[start])

        collection.pop()  # remove repetition

        # advancing branch
        self.dfs(start + 1, collection, total)

target = 9

print(Solution().combinationSum(nums, target)) #  == [[2,2,5],[9]]

target = 16

** Approach 2

- sort candidates in ascending order
- Use dfs backtracking to enumerate all possible terms that add up to the target
  - In this case, do recursive dfs only for the repeating branch
  - Advancing will be done in a for loop with early stopping when
    adding a candidate exceeds the target

** Solution 2

#+begin_src python
from typing import List

class Solution:
    def combinationSum(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        self.candidates = nums
        self.target = target
        self.results = []

        self.dfs(0, [], 0)

        return self.results

    def dfs(self, start, collection, total):
        if total == self.target:
            self.results.append(collection.copy())
            return

        for i in range(start, len(self.candidates)):
            # advance from start
            if total + self.candidates[i] > self.target:
                # adding current and all subsequent candidates exceeds target
                return

            # repeats for candidates[i]
            collection.append(self.candidates[i])
            self.dfs(i, collection, total + self.candidates[i])
            collection.pop()

nums = [2,5,6,9]
target = 9

print(Solution().combinationSum(nums, target)) #  == [[2,2,5],[9]]

target = 16

nums = [3]
target = 5

print( Solution().combinationSum(nums, target)) #  == []

** Analysis

Given n = len(candidates), t = len(candidates) and m is min(candidates)

*** Space complexity

O(t/m) - recursion stack

*** Time complexity

O(2^{t/n}) - two branches (repeating, advancing) for a depth of upto t/n

O(n * 2^{t/n}) - Overall for all candidates
