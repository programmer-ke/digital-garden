* Longest Common Subsequence

** Description

https://leetcode.com/problems/longest-common-subsequence/description/

** top down dynamic programming with memoization

*** Approach

- Recusively match each position in the two strings to identify
  longest matching subsequence
- where there is no match, identify subsequent matches by advancing
  on either string exclusively and finding the maximum
- Cache intermediate results to prevent repeated computation

*** Solution

#+begin_src python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        self.memo = {}
        self.t1, self.t2 = text1, text2
        return self.find_longest(0, 0)

    def find_longest(self, i, j):
        if i == len(self.t1) or j == len(self.t2):
            return 0
        if (i, j) in self.memo:
            return self.memo[(i, j)]

        if self.t1[i] == self.t2[j]:
            self.memo[(i, j)] = 1 + self.find_longest(i + 1, j + 1)
        else:
            self.memo[(i, j)] = max(self.find_longest(i + 1, j), self.find_longest(i, j + 1))
        return self.memo[(i, j)]

** Bottom up dynamic programming

*** Approach

- Create a grid representing each word on either axis
  - each position (i, j) will represent the longest matching
    subsequence seen in text1[i:] and text2[j:] suffixes
  - traversing from ends of either string, when chars at i, j match,
    add on to the lower right diagonal (represents advancing both strings)
  - when they don't match set cell value to max of right or bottom
    values (representing advancing either string)
  - return value at i, j = 0, 0 (top left of grid)
- A space optimization to make is to realize we only need the current
  and previous rows in the grid
  
*** Solution

#+begin_src python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        if len(text1) > len(text2):
            longer, shorter = text1, text2
        else:
            longer, shorter = text2, text1

        curr = [0] * (len(shorter) + 1)
        prev = [0] * (len(shorter) + 1)

        for i in range(len(longer) - 1, -1, -1):
            for j in range(len(shorter) - 1, -1, -1):
                if longer[i] == shorter[j]:
                    curr[j] = 1 + prev[j + 1]
                else:
                    curr[j] = max(curr[j + 1], prev[j])
            prev, curr = curr, prev
        return prev[0]
