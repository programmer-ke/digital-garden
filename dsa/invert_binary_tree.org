* Invert Binary Tree

** Description

You are given the root of a binary tree root. Invert the binary tree
and return its root.

Example 1:

Input: root = [1,2,3,4,5,6,7]

Output: [1,3,2,7,6,5,4]


Example 2:


Input: root = [3,2,1]

Output: [3,1,2]

Example 3:

Input: root = []

Output: []
Constraints:

0 <= The number of nodes in the tree <= 100.
-100 <= Node.val <= 100

** Approach

Inverting is like flipping the tree from left to right.

For each node, we need to invert each left and right subtree, followed
by inverting the left and right child nodes.

This means that we can use recursive post order traversal to achieve this.

** Solution

#+begin_src python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if root:
            root.left = self.invertTree(root.left)
            root.right = self.invertTree(root.right)

            root.left, root.right = root.right, root.left
        return root

#+end_src

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        stack = [root]
        while stack:
            node = stack.pop()
            if node:
                stack.append(node.left)
                stack.append(node.right)
                node.left, node.right = node.right, node.left
        return root
        
#+end_src

** Further Discussion

_Me_:

I notice that order doesn't matter, any of pre-order, in order and
post order can be used. Is this correct?

_AI_:

Correct, height can be O(n) for a skewed tree (e.g., a chain).

Regarding traversal order: *not exactly*.

- *Pre-order*: swap children, then recurse on both → works.
- *Post-order*: recurse on both, then swap → works.
- *In-order*: naive left-root-right does *not* work. If you invert
  left, swap, then invert right, you might undo the inversion. You'd
  need to handle it specially (invert left, swap, then invert the
  /new/ left).

So the simple recursive version typically uses pre- or post-order.

_Me_:

What other approaches exist to solve this?

_AI_:

Other approaches:

- /BFS (level-order)*: use a queue. Pop a node, swap its children,
  then enqueue its children (if they exist). Also O(n) time, O(n)
  space.
- /Iterative DFS with two stacks/: post-order variant, but
  unnecessary.
