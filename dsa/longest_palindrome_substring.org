* Longest Palindrome Substring

** Description

Given a string s, return the longest substring of s that is a
palindrome.

A palindrome is a string that reads the same forward and backward.

If there are multiple palindromic substrings that have the same
length, return any one of them.

Example 1:

Input: s = "ababd"

Output: "bab"

Example 2:

Input: s = "abbc"

Output: "bb"
Constraints:

1 <= s.length <= 1000
s contains only digits and English letters.

** Approach 1

A dynamic programming approach:

- Use a table to track which indices that delimit a valid palindrome
- When a valid palindrome is found in the among the possibilities of all substrings,
  mark as True in table
  - a palindrome is valid if both its start and end letter are equal and
    - length is <= 3 or if removing its first and last letters leaves a valid palindrome
- Identify the longest such substring

** Solution 1

#+begin_src python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        start_p, length_p = 0, 0
        n = len(s)
        valid_palindrome = [[False] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):  # work backward to ensure we can check table[i + 1]
            for j in range(i, n):
                if s[i] == s[j] and (j - i <= 2 or valid_palindrome[i + 1][j - 1]):
                    valid_palindrome[i][j] = True
                    if (j - i + 1) > length_p:
                        start_p, length_p = i, (j - i + 1)
        return s[start_p:start_p + length_p]

s = "ababd"

# Output: "bab"

** Approach 2

- Assume each character in the string is the centre of the palindrome
  - iterate from either side and detect palindromes tracking the longest found
  - For each character check both odd length palindrome (i = centre) and
    even length palindrome (i, i+1 are the two centres) 

** Solution 2

#+begin_src python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        start_p, length_p = 0, 0
        for i in range(len(s)):
            # even length
            l, r = i, i+1
            while 0 <= l < r < len(s) and s[l] == s[r]:
                if (r - l + 1) > length_p:
                    length_p = r - l + 1
                    start_p = l
                l -= 1
                r += 1
            # odd length
            l, r = i, i
            while 0 <= l <= r < len(s) and s[l] == s[r]:
                if (r - l + 1) > length_p:
                    length_p = r - l + 1
                    start_p = l
                l -= 1
                r += 1
        return s[start_p:start_p + length_p]
