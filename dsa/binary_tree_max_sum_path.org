* Binary Tree Maximum Sum Path

** Description

https://neetcode.io/problems/binary-tree-maximum-path-sum/

** Approach

Through each node there are 3 possible path sums:

- left -> node -> right
- left -> node -> parent
- right -> node -> parent

While tracking the best path sum seen so far, we can traverse
the tree with dfs. At each step:

- update best path sum if left -> node -> right improves it
- return best of left -> node and right -> node to parent

Negative sums from left or right can be ignored because they always
have a decreasing effect on the path sum

Constraints:

1 <= The number of nodes in the tree <= 30000.
-1000 <= Node.val <= 1000

** Solution

#+begin_src python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        if root is None: return float('-inf')
        
        self.max_sum = root.val
        self.dfs(root)
        return self.max_sum

    def dfs(self, node):
        if node is None: return float('-inf')

        left_sum = max(self.dfs(node.left), 0)
        right_sum = max(self.dfs(node.right), 0)
        # consider sum of left -> node -> right
        self.max_sum = max(self.max_sum, left_sum + node.val + right_sum)
        # allow parent to consider (left|right) -> node -> parent
        return max(left_sum, right_sum) + node.val
        
#+end_src

** Analysis

*** Time complexity

O(n) - We visit each node once doing constant work.

*** Space complexity

O(h), where h == n worst case (skewed tree) for the recursion stack
