* Maximum Subarray

** Description

https://neetcode.io/problems/maximum-subarray/question

** Dynamic programming

*** Approach

- at each position after the first in the numbers array we make
  a choice to maximize the subarray sum:
  - increment the previous subarray sum
  - start a new subarray sum
- Store the sums in another array and find the maximum

*** Solution

#+begin_src python
from typing import List

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        fnum = nums[0]
        sums = [fnum] * len(nums)

        for i in range(1, len(nums)):
            sums[i] = max(nums[i], nums[i] + sums[i-1])

        return max(sums)

** Kadane's algorithm (sliding window)

*** Approach

- The goal is to maximize sum, so we maintain a sum of the current
  window.
  - any time we advance, if the sum of the previous window is negative,
    we start a new window sum (-ve numbers always decrease the sum)
  - add the new value to current window sum and compare with the maximum
    seen so far
  - At the end, return the maximum sum seen

*** Solution

#+begin_src python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        cur_sum = max_sum = nums[0]
        for i in range(1, len(nums)):
            if cur_sum < 0:
                cur_sum = 0
            cur_sum += nums[i]
            max_sum = max(max_sum, cur_sum)
        return max_sum
